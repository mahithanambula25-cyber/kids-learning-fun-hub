# 🎨 Kids Learning Fun Hub 📚

A fully interactive web application designed to make learning fun and engaging for kids, featuring built-in educational tools, a multi-tool digital drawing canvas, and accessibility features.

## 🚀 Live Demo
Check out the live application hosted on Netlify: [Kids Learning Fun Hub Live](https://kidshublearning-56c905.netlify.app)

---

## ✨ Features
- **🔤 English & Regional Learning:** Interactive sections for language and vocabulary building.
- **🔢 Fun Maths & Counting:** Engaging math puzzles and arithmetic challenges.
- **🇮🇳 Telugu Learning:** Regional language modules with clean UI layout.
- **✏️ Ultimate Kids Drawing Studio:** 
  - Custom brush styles (Water Paint, Pencil, Crayon, Calligraphy, Eraser).
  - Multi-touch support for tablets and mobile touch screens alongside desktop mouse support.
  - Interactive shapes toolbar (Rectangles, Circles, Triangles, Stars, and Arrows).
  - Ability to clear and save drawings instantly.

---

## 🛠️ Tech Stack
- **HTML5** (Canvas API, Semantic Structure)
- **CSS3** (Responsive design, Flexbox, custom styling)
- **JavaScript (ES6+)** (DOM Manipulation, Event Handling, Touch/Mouse event listeners, Speech Synthesis API)
